# GWA6_BloodSomaticExpansionRatioPhenotype
The R script GWA6_BloodSomaticExpansionRatioPhenotype_GeM-HD2025_NatureGenetics.R processes the blood somatic expansion data from GeM-HD 2025 Nature Genetics (in prep., see preprint at https://doi.org/10.1101/2024.06.10.597797) to 1) caclulate the blood SER phenotype for the somatic expansion GWAS (as described in the section "Blood somatic expansion ratio phenotype" of the methods section), and 2) make Figure 2A and 2B

The relevant data can be requested as "GWA123456 publication data" from CHDI.

The specific data file processed by the script is 3999_individuals_GWA6_SER10_and_vars_associated_with_raw_phenotype.xlsx

Required packages to run that script:
readxl and ggplot2
